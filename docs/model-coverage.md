Use fresh independently reviewed RAW decision cases and a separate baseline/candidate comparison; BexDog's reported preference is not a RAW measurement. For actual reasoning coverage, approve a bounded model/environment/resource combination first. Preserve the intended thinking behavior in reviewed targets and the exact tokenizer/template and evaluation settings. Measure multi-step task quality, evidence comparison, errors, regressions, latency and owned memory. A longer response is not evidence of better reasoning.
